# 🏫 Sistema de Aula Virtual

Este es un proyecto web desarrollado en **PHP** y **MySQL** diseñado para la gestión académica interna de una institución educativa.

## 🚀 Módulos del Sistema
* **Panel de Administración:** Control total sobre asignaciones, docentes, estudiantes, grados y materias.
* **Control de Notas:** Planilla digital interactiva para que los docentes registren y actualicen calificaciones.
* **Sección de Alumnos:** Vista dedicada para que los estudiantes consulten sus reportes y tareas pendientes.
* **Reportes en PDF:** Generación automática de boletines escolares utilizando la librería FPDF.

## 🛠️ Tecnologías utilizadas
* **Backend:** PHP 8.x
* **Base de Datos:** MySQL (entorno local con XAMPP)
* **Reportes:** FPDF
